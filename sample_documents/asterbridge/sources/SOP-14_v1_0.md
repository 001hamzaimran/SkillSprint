# Returns Inspection and Disposition Procedure

Document SOP-14 | Version 1.0 | Approved | Effective 2026-09-01
Owner: Operations Manager | Approval authority: Managing Director | Scope: Returns Specialist
Review due: 2027-09-01 | Valid until: No scheduled expiry

## Purpose and application
Assess returned parcels against evidence and route refund or disposal decisions to the correct authority.

Role mandate: Assess returns consistently and authorize only permitted disposition actions. Reports to: Operations Manager. Department: Returns. Delegated authority is limited to the steps below; independent financial or policy approval remains with the named approver.

## 4.1 Register the return
REQ-SOP-14-01 | Mandatory
The Returns Specialist must create a return record linked to the shipment, reason and requesting party before inspection. A duplicate request must link to the existing return.
Evidence: Return identifier and original shipment link.

## 4.2 Confirm eligibility
REQ-SOP-14-02 | Mandatory
The Returns Specialist must check the recorded merchant service terms and approved return reason before deciding eligibility. Missing or conflicting terms require Operations Manager review.
Evidence: Eligibility evidence and any review decision.

## 4.3 Inspect condition
REQ-SOP-14-03 | Mandatory
The Returns Specialist must inspect packaging and contents using the approved safe-inspection process and record observed condition. Photographs must exclude unnecessary customer identifiers.
Evidence: Inspection checklist and controlled evidence.

## 4.4 Separate assessment and payment
REQ-SOP-14-04 | Mandatory
The Returns Specialist must recommend an eligible refund amount with evidence but must not execute payment. The Finance Associate processes independently approved refunds under SOP-16.
Evidence: Refund recommendation and separate payment record.

## 4.5 Control high value returns
REQ-SOP-14-05 | Mandatory
The Returns Specialist must obtain Operations Manager approval for a recommended refund above PKR 10,000 before forwarding it to Finance. Splitting a refund to avoid approval is prohibited.
Evidence: Value assessment and manager approval.

## 4.6 Authorize disposition
REQ-SOP-14-06 | Mandatory
The Returns Specialist must obtain a recorded disposition decision before returning stock to a merchant, restocking or disposing of goods. Disputed ownership requires a hold.
Evidence: Disposition authority and custody record.

## 4.7 Close the return
REQ-SOP-14-07 | Mandatory
The Returns Specialist must reconcile physical disposition and the financial outcome before closing a return. Any unresolved balance or custody issue must remain visible.
Evidence: Closure reconciliation and outstanding-issue status.

## 4.8 Analyze return reasons
REQ-SOP-14-08 | Recommended
The Returns Specialist may summarize recurring return causes for merchant reviews using aggregated information.
Evidence: Optional return trend summary.

## Training and control
Employees learn the applicable clauses during Week 1 and complete a source-based knowledge check. Task performers demonstrate the relevant procedure before independent work. Mandatory knowledge checks require at least 80 percent; all safety and privacy critical steps must pass. The assessor records requirement IDs, evidence and the source version. An earlier operational deadline still applies. Questions and exceptions follow POL-01; related controls include POL-01, POL-03, POL-05, POL-06 and POL-09.
